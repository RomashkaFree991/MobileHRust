# Rust → Godot 4: мобильное FPS-демо

Проект Godot **4.5.1+** (тестовая версия на 4.5.1-stable, рендерер **Mobile**, ландшафтная ориентация, тач-управление).
Прототип использует ресурсы из присланного архива Rust (Unity 2019.4); перенос в Godot неполный.


## Экспериментальная версия: инвентарь и персонаж

**Не готовый перенос Rust:** интерфейс и логика сделаны заново для прототипа, не извлечены полностью из исходной игры. Тестовая конвертация анимаций требует исправления ретаргетинга. Данные клипов и скрипт конвертации лежат в `tools/`.

Инвентарь: 24 ячейки, 6 слотов пояса, 7 слотов одежды (предметов одежды пока нет); перенос и объединение предметов, переключение оружия и расход патронов при перезарядке. Полный функционал Rust (крафт, выброс, разделение стопок, броня и пр.) отсутствует.
- Текстуры и иконки AK, полуавтоматического пистолета и револьвера заменены на стандартные из полного архива; камень не менялся.
- На телефоне кнопка «ИНВЕНТАРЬ» открывает упрощённое окно с моделью персонажа слева, 24 ячейками и поясом. Запасы патронов показаны отдельно для каждого оружия и уменьшаются при перезарядке. Полного переноса интерфейса Rust и перетаскивания предметов пока нет.
- Кнопка «ПРИСЕСТЬ» переключает приседание. Кнопка «ВИД» переключает от первого лица к третьему, в первом лице ноги отключены. На ПК: Ctrl, V, Tab.
- Перенесена геометрия и текстуры тела/головы из архива; шорты упрощены, внешний вид ещё не совпадает с оригиналом. Экспериментально конвертированы кривые Humanoid для 7 клипов (покой, ходьба, бег, присед, ходьба в приседе, прыжок, предпросмотр). Из-за различий скелетов позы заметно искажены; это НЕ корректный полный перенос анимаций. В третьем лице оружие в руках пока не отображается. На телефоне версия не проверена.
- APK — отладочная сборка для Android arm64 и Vulkan. У этого выпуска отдельный идентификатор приложения: он устанавливается рядом с прошлой версией.
- Оптимизация для телефона: рендер 3D на 85% размера, менее плотная трава, более лёгкие тени, без MSAA и свечения. Ограничение FPS в движке снято, но 120 FPS и частота экрана зависят от телефона и Android и не гарантируются. Проверка производительности на реальном устройстве ещё нужна.

## Что есть
- **Сцена**: площадка 600×600 м с текстурой травы/мха (Rust `moss_a`) + трава MultiMesh с ветром
  (участок 80×80 м, дальность на телефоне ~36 м), 8 объектов Rust с LOD и коллизией: контейнер, ящики, бочка, hesco,
  коробки, конус и т.д. Небо/туман/тени — штатные Godot.
- **Руки с оружием** (viewmodel Rust, все клипы): АК (Assault Rifle), Semi-Automatic Pistol, Revolver,
  **Rock** — ближний бой (удар, добыча) + бросок.
- **Действия**: стрельба (hitscan, разброс, отдача, авто/полуавто), прицеливание (ADS по точкам
  IronSights из префабов Rust: совмещение мушки/целика, FOV −30°/−10°, zoomFactor), перезарядка,
  осмотр (admire), холостой щелчок при пустом магазине, смена оружия (deploy), бег/прыжок, покачивание.
  Кнопка «АНИМ» по очереди проигрывает **все** анимации текущего оружия.
- **Эффекты** (воссозданы из префабов Rust по их параметрам — `assets/fx/*.json`): вспышка дула +
  свет, дым, трассер, гильзы с физикой и звуком падения, попадания по траве/земле/дереву/металлу/бетону
  (искры, щепки, пыль) + декали пулевых отверстий, эффекты удара камнем.
- **Звуки**: выстрелы, перезарядка/осмотр по событиям анимаций, сухой щелчок, попадания, шаги, гильзы, фон.
- **Интерфейс Rust**: пояс из 6 ячеек (иконки предметов, число патронов, полоска прочности),
  здоровье/вода/еда, счётчик патронов, шрифты Roboto Condensed + Font Awesome как в игре.

## Управление
**Телефон**: левая часть экрана — плавающий джойстик (до края = бег), правая — обзор свайпом;
кнопки: огонь (можно вести прицел, не отпуская), ПРИЦЕЛ (переключатель), R — перезарядка,
ОСМОТР, прыжок, бег (переключатель), ПРИСЕСТЬ, ВИД, ИНВЕНТАРЬ, АНИМ; тап по ячейке пояса — выбор оружия.
У камня: ПРИЦЕЛ — замах, огонь — бросок; огонь без прицела — удар.

**ПК**: WASD, мышь, ЛКМ — огонь, ПКМ или Q — прицел, R, F — осмотр, N — следующая анимация,
1–6 / колесо — оружие, Shift — бег, Space — прыжок, Ctrl — присед, V — вид, Tab — инвентарь, Esc — отпустить мышь,
**T** — скрыть или вернуть сенсорные кнопки; ввод мышью при этом остаётся активен.

**Android с мышью и клавиатурой:** подключите устройства по Bluetooth или USB OTG, если телефон их поддерживает. Управление такое же, как на ПК. На Android игра пробует захватить курсор при движении физической мыши; щелчок в игровом поле повторно захватывает его, Esc отпускает. Tab открывает инвентарь и освобождает курсор; после закрытия захват восстанавливается, если он был активен. На экране остаётся маленькая кнопка «КНОПКИ», чтобы вернуть сенсорное управление без клавиатуры. Сохраняются игровой интерфейс и счётчик FPS; диагностический текст убран. Последнее исправление обзора пока не проверено на настоящем Android-устройстве.

## Запуск и экспорт на Android
1. Открыть папку в Godot 4.3+ (первый импорт ~1–2 мин) → F5.
2. Editor → Manage Export Templates → Download and Install.
3. Editor Settings → Export → Android: путь к Android SDK и Java 17 (debug keystore создаётся автоматически).
4. Project → Export → пресет **Android** уже настроен (arm64-v8a, ETC2/ASTC, включены `*.json`,
   immersive mode) → Export Project (`export/rust_demo.apk`) или One-click deploy.

## Структура
| Файл | Что делает |
|---|---|
| `scenes/main.tscn`, `scripts/main.gd` | окружение, земля (шейдер), трава, объекты + коллизии, input map, спавн игрока/HUD |
| `scripts/player.gd` | контроллер игрока: движение, обзор мышь/тач, шаги, отдача, тряска |
| `scripts/weapon_manager.gd` | таблица `WEAPONS` (смещения, кости дула/гильзы, имена клипов, звуки по времени, магазины) и машина состояний |
| `scripts/fx.gd` (autoload `FX`) | частицы из JSON → CPUParticles3D, пулы, вспышки света, декали, гильзы, 2D/3D звук |
| `scripts/hud.gd` | HUD, пояс, показатели здоровья, тач-кнопки, джойстик, мультитач |
| `scripts/autotest.gd` | авто-прогон: `godot --path . -- --autotest [--scenario=fx / promo] [--shots=папка]` |
| `assets/weapons, props, fx, decals, env, sounds, ui` | ассеты Rust (GLB + PNG/JPG + OGG) |

Добавить оружие: положить `v_*.glb` в `assets/weapons/<имя>/`, добавить запись в `WEAPONS`
(анимации берутся по именам клипов из GLB), иконку — в `hud.gd`.

## Замены и ограничения
- Текстура рук от первого лица пока однотонная, используется материал `ViewModel_Arms`. Для оружия использованы исходные цветовые карты; карты скинов отключены.
- Нет оригинальной текстуры террейна/травы Rust → земля из `moss_a`, травинки из текстуры частиц травы.
- Эффекты Rust (Unity Shuriken) перенесены приблизительно: те же текстуры/атласы, цвета, размеры,
  время жизни, скорости; кривые упрощены.
- Модели Unity имеют левостороннюю систему координат — при конвертации ось X зеркалирована (учтено).

## Правовое
Ассеты принадлежат Facepunch Studios (Rust). Использовать только для личного обучения/прототипа;
для публикации/продажи замените их собственными.

Движок обновлён до Godot 4.5.1 из-за ошибки обработки относительного движения в версии 4.3. Дополнительно можно удерживать **Q** для прицела и стрелять левой кнопкой мыши: это обходной вариант, если телефон не передаёт обе кнопки мыши одновременно.
